# Ben 10: Protector of Earth — PC Edition Launcher

A lightweight, open-source PC front-end launcher for **Ben 10: Protector of Earth** (Nintendo Wii edition). Designed to provide a seamless desktop experience with native keyboard & mouse motion bindings, 16:9 widescreen, and automatic upscaling up to 4K 60 FPS without manual emulator setup.

## Features
- **One-Click Launch:** Automatically injects graphics, fullscreen, and input configurations before starting the game.
- **PC Controls Ready:** Converts Wii remote shake gestures into responsive Left/Right mouse clicks (`WASD` + Mouse) alongside full XInput gamepad support.
- **HD/4K Upscaling:** Built-in presets from 480p Native up to 4K Ultra HD (`Direct3D 11`).
- **Portable Architecture:** Keeps all settings and profiles self-contained next to the executable.

## Default PC Controls (Keyboard & Mouse)

| Action | Key |
| :--- | :--- |
| **Move** | `W` `A` `S` `D` |
| **Jump / Double Jump** | `Spacebar` |
| **Light Attack (Wiimote Shake)** | `Left Click` |
| **Heavy Attack (Nunchuk Shake)** | `Right Click` |
| **Block / Grab / Interact** | `Left Shift` |
| **Alien Transformations** | `1` `2` `3` `4` |
| **Camera / Cycle Forms** | `Q` / `E` |
| **Pause & Upgrades** | `ESC` / `Tab` |

## Setup & Usage
1. Download the latest `Ben10Launcher.exe` from the **Releases** or **Actions** tab.
2. Download the portable **Dolphin Emulator (Windows x64)** from [dolphin-emu.org](https://dolphin-emu.org) and extract it into a `Dolphin` folder next to `Ben10Launcher.exe` (create an empty `portable.txt` inside `Dolphin/`).
3. Run `Ben10Launcher.exe`, select your legally dumped `.rvz` or `.iso` game image, choose your resolution and control scheme, and click **PLAY GAME**.
